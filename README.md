# Number Checker 🔢

A simple, responsive web app that checks and categorizes numbers.

**Live Demo:** https://jaftermaluleka98.github.io/number-checker/

## Features
- Checks if number is positive, negative, or zero
- Categorizes as small (1-99), large, etc.
- Checks if number is even or odd
- Beautiful responsive design
- Instant feedback

## How it works
1. Enter any number
2. Click "Check Number"
3. See the result instantly

## Technologies Used
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to run locally
1. Clone this repo
2. Open `index.html` with Live Server or double-click it
